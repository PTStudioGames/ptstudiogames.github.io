Blender MultiShot Render

Each shot its own camera, size, frames and collections

MultiShot Render keeps a list of shots in one Blender file, each with its own camera, resolution, frame range, output folder and collection visibility. Tick the shots you want and click Render Checked: every shot renders into its own folder and your scene comes back exactly as it was.

The problem it solves

Rendering the same scene several ways usually means re-setting it by hand before each render: switch the camera, type a new resolution, change the frame range, hide or show collections, change the output path, render, and then undo it all for the next one. MultiShot Render stores that setup once per shot, so you set it up once and render all of them in one click.

Features

  • Per-shot camera.
  • Per-shot resolution and resolution %.
  • Per-shot frame range, or a single still frame.
  • Per-shot output subfolder under one base output folder.
  • Saved collection visibility per shot: capture which collections are excluded, and that shot renders with them.
  • Render Checked: renders every ticked shot in one click, with progress shown in the status bar.
  • Esc cancels a running render.
  • Your scene's camera, resolution, frame range, output path and collection state are restored afterwards.
  • No temp files: each shot writes straight into its own folder.
