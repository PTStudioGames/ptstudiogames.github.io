Blender MultiShot Render

Each shot its own camera, size, frames and collections

MultiShot Render keeps a list of shots in one Blender file, each with its own camera, resolution, frame range, output folder and collection visibility. Tick the shots you want and click Render Checked: every shot renders into its own folder and your scene comes back exactly as it was.

The problem it solves

Rendering the same scene several ways usually means re-setting it by hand before each render: switch the camera, type a new resolution, change the frame range, hide or show collections, change the output path, render, and then undo it all for the next one. MultiShot Render stores that setup once per shot, so you set it up once and render all of them in one click.

Features

  • Per-shot camera.
  • Per-shot resolution and resolution %.
  • Per-shot frame range, or a single still frame.
  • Per-shot output subfolder under one base output folder.
  • Saved collection visibility per shot: capture which collections are excluded, and that shot renders with them.
  • Render Checked: renders every ticked shot in one click, with progress shown in the status bar.
  • Esc cancels a running render.
  • Your scene's camera, resolution, frame range, output path and collection state are restored afterwards.
  • No temp files: each shot writes straight into its own folder.

Stagelight Product Studio

One-click product studio: lights, backdrop, camera, turntable

Stagelight Product Studio is a Blender add-on for anyone who needs a clean product shot without placing lights by hand. Select your mesh and click Build Studio: it makes a backdrop, key, fill and rim lights and a camera around the selection and sizes them to it. Pick one of four looks and a backdrop colour, then render a still or a turntable PNG sequence in Eevee or Cycles.

The problem it solves

A product shot needs a backdrop, three lights and a camera that frame the object, and every new object means moving all of it again. Stagelight builds the rig around whatever you select, so a bottle, a shoe or a whole table of props gets the same studio in one click, and Remove Studio takes it away again.

Features

  • Build Studio: a backdrop sweep, key, fill and rim lights, a camera and a pivot, fitted to the selected meshes.
  • Fits the selection: tested from objects 0.01 units across to objects 100 units across.
  • Four looks: Soft, Dramatic, High Key and Warm / Cool, plus a backdrop colour. Rebuild to switch look.
  • Building again replaces the studio; you never get two.
  • Render Still in Eevee or Cycles with the sample count you set. Glass is set up for the render and your own render settings are put back afterwards.
  • Render Turntable: a PNG sequence of one full turn, with the number of frames you choose.
  • Remove Studio deletes everything the add-on made and restores your scene camera. Your objects are never moved.
  • One studio per scene, so several scenes can each have their own.
  • A README is inside the zip, and every setting has a tooltip.
  • Pure Python on Blender's own modules: nothing else to install.

Decal Stamp

Stamp image decals that bake: Principled inputs, no Mix Shader

Decal Stamp puts logos, labels and badges on any mesh in a click. Pick an image and it is projected onto the active object through an Empty: move, rotate or scale the Empty and the decal slides over the surface. Every decal sits in a list with its own opacity and edge fade, and the whole stack feeds the material's Principled BSDF inputs directly, so it renders in Eevee and Cycles and bakes into textures like any other colour.

The problem it solves

Putting a logo on a product usually means UV-unwrapping, painting or a Mix Shader per decal. Mix Shader decals look fine in a render but come out wrong or missing when you bake the material to textures for a game engine or a web viewer. Decal Stamp mixes into the Base Color, Roughness and Normal inputs instead, so what you render is what you bake, and no UV work is needed to place a decal.

Features

  • Stamp Decal: pick an image; it is projected onto the active mesh from the 3D cursor, facing the view, sized to the image's aspect.
  • One Empty per decal is its projector: move, rotate and scale it to place the decal.
  • A decal list in the 3D Viewport sidebar (Decals tab): show or hide each decal, add, remove, duplicate and reorder. The top decal wins where decals overlap.
  • Per decal: opacity, edge fade, an optional roughness value and a normal strength that embosses the image.
  • Duplicate copies a decal and its settings onto a new Empty beside the original, ready to move.
  • Selecting a decal's Empty in the viewport selects it in the list.
  • Bakes: the decals feed the Principled BSDF's Base Color, Roughness and Normal inputs through one "Decal Stack" node group, with no Mix Shader. A Cycles Diffuse colour bake shows them in the texture.
  • Non-destructive: removing the last decal reconnects your original inputs and deletes the node group.
  • Eevee and Cycles. Blender 4.2 to 5.x.

Camera Moves

Stack eased A to B camera moves and build the timeline

Camera Moves turns camera animation into a list. Pose a camera, click Set A; move it, click Set B; pick a duration and an easing. Stack as many moves as you like, on one camera or several, then click Build Timeline: every move is keyed end to end from the scene start, with a marker that switches to its camera. Change a duration or the order and build again.

The problem it solves

A product turntable, an archviz walkthrough or a showreel usually needs a handful of simple camera moves: a push-in, a slide, a crane up. Keying each one by hand, fixing its curves, then shifting every later key when one changes length takes longer than the shots themselves. Camera Moves stores each move as two poses and lays them out for you.

Features

  • Works with your own cameras: each move uses any camera in the scene, picked from a camera-only field.
  • Set A / Set B store the camera's location, rotation and focal length; Go A / Go B put it back there.
  • Per-move duration in frames and easing: Linear, Ease In-Out or Smooth.
  • A move stack: add, remove, reorder, and tick moves on or off.
  • Build Timeline keys the ticked moves end to end from the scene's start frame, adds a timeline marker bound to each move's camera, and sets the scene's end frame to the last move's end.
  • Rebuilding is exact: it first clears the location, rotation and focal-length keys inside the range it built last time and its own markers (named "CM ..."), so keys outside that range and your other markers stay.
  • Per-move handheld shake (0 to 1): a noise on the camera's rotation, limited to that move's frames and faded in and out.
  • Render A/B stills: one click renders each ticked move's start and end poses to <output folder>/<move>/<move>_A.png and _B.png, then puts the camera, frame and output path back.
  • Blender 4.2 to 5.x.
